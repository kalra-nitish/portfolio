# Avatar Image Placeholder

Please save your avatar image as `nitish-avatar.jpg` in this directory.

The image should be:
- Square aspect ratio (1:1)
- At least 400x400 pixels
- Good quality with clear face visibility
- JPG or PNG format

The InteractiveAvatar component will automatically:
- Make the eyes follow mouse movement
- Add subtle head tilting based on mouse position
- Apply smooth animations and transitions
- Add a subtle glow effect
